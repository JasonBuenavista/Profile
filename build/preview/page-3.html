User Pathways & Navigation Rules

Who arrives, what they need, and the shortest route the structure gives them.

01Recruiter / hiring managerScreen fast, verify credentials, make contact.
Home/→About/about→Resume/resume.pdf→Contact/contact
Resume downloadable above the fold in About. The form asks for nothing a CV already answers. Target: 3 clicks, under 90 seconds.
Signal — resume download, or a message that references the About page.
02Prospective clientJudge the thinking, then enquire about a project.
Home/→Featured: LISplus/work/lisplus→Results/work/lisplus#results→Next: StudySmart/work/studysmart→Contact/contact#form
Next/previous links keep a client reading instead of hitting the nav. Every case study ends with results plus a persistent contact CTA.
Signal — an enquiry that names the project they read about.
03Recruiter from GitHubArrive from the profile, judge the code, then read the story.
GitHub profileexternal→StudySmart/work/studysmart→Work index/work→About/about#bio
GitHub is your strongest referral source: each repo links to its case study, and the case study links back to the index and to you.
Signal — referral traffic that continues into the index or About instead of bouncing.
04Returning visitorRe-find one project, filtered by discipline.
Home/→Work index/work→Filter/work?filter=web-apps→StudySmart/work/studysmart
Filters persist in the URL so a shortlist can be bookmarked or shared. Filter state never hides content from crawlers.
Signal — a filtered view revisited, bookmarked, or forwarded.

Navigation rules

  • Every case study is reachable from the homepage in two clicks.
  • Primary nav never changes between pages and never exceeds four items plus the logo.
  • Case studies carry breadcrumbs: Home / Work / LISplus.
  • No orphan pages: every project is linked from /work and the homepage.
  • The 404 page returns a real 404 status and offers Home and Work.
  • Mobile keeps the same four items in a drawer; nothing lives only in a hover menu.

Technical & SEO checklist

  • sitemap.xml lists the three project pages; referenced in robots.txt.
  • One canonical URL per page; ?filter= views canonicalise to /work.
  • Unique title and meta description per project; OG image (1200×630) per case study.
  • JSON-LD: Person on Home/About, CreativeWork + BreadcrumbList on each project.
  • Screenshots of LISplus and StudySmart get descriptive alt text; below-fold images lazy-load.
  • Slug changes ship with a 301 map; unfinished projects stay out of the index.
